💡 HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════════

User tries to access protected route without authentication:

  1. GET /profile (no session)
  2. Laravel checks auth middleware
  3. Auth fails → AuthenticationException thrown
  4. Exception handler catches it
  5. Renders custom 401 page (or JSON response)
  6. User sees: "Akses Ditolak" page
  7. User clicks "Login Sekarang"
  8. Modal auth opens
  9. User logs in
  10. Modal closes
  11. Redirects to /profile
  12. Profile page loads ✅
